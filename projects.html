CMPS 285 CampusEvents Website

Collaborated in a team of five to develop a full-stack web application called Campus Events for a Software Engineering course. The platform was designed to enhance student engagement by centralizing all campus-related events and organization activities into one accessible interface. Users could browse various student organizations, join groups, RSVP to upcoming events, and participate in real-time chat discussions. The frontend was built with React, TypeScript, and Mantine UI. On the backend, we used C#, .NET, and Node.js to handle user registration, event management, and chat functionality. We also implemented features like filtering, membership tracking, and notifications. Git was used for version control, enabling team collaboration and Agile workflows.
